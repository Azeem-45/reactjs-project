# HealthCareJS

HealthCareJS is a React.js-based healthcare web application.  
It provides user authentication, home dashboard, and health assessment forms (HIT-6 and NPHQ) to help users track their health status.

---

## Features

- **User Authentication:**  
  - Login form  
  - Registration form  

- **Home Page:**  
  - Dashboard with overview and navigation  

- **Health Forms:**  
  - **HIT-6 Form:** For measuring headache impact  
  - **NPHQ Form:** For assessing patient health questionnaire  

- **Responsive Design:**  
  - Works on desktop and mobile screens  

---

## Tech Stack

- **Frontend:** React.js  
- **Routing:** React Router  
- **State Management:** React Hooks / Context API (if used)  
- **Styling:** CSS / SCSS / Tailwind (depending on implementation)
